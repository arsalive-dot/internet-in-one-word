An entry for make.fun's [The Internet in One Word](https://make.fun/bounty/u-ronigrv-the-internet-in-one-word-e388f33b) bounty: one word describing the whole internet — **feral**. Wild, unmoderated, full of strange creatures that cannot be domesticated; funny by itself, true about the internet as a whole, and five letters long so it lands in one beat.

`main.py` (Python 3, stdlib only) writes the word to `/output/entry.txt`, deterministically, via a temp file plus rename with mode 644.
